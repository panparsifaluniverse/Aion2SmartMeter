# A2Companion

Free modular companion for Aion 2. Previously named Aion2SmartMeter.

[Download the latest Companion release](https://github.com/panparsifaluniverse/Aion2SmartMeter/releases/latest)

Extract the release ZIP and run the EXE. Select the tools you want from **Modules**. Companion installs and updates each module independently from GitHub, using a signed catalog and SHA-256 verification. English, Italian and Estonian are supported.

Only Companion releases use **Latest**. Module releases use separate tags and do not replace the application update channel.

The signed module catalog is available at [`module-repository/catalog.json`](module-repository/catalog.json). Installed module preferences and character data are preserved during module updates and removal.

The combat bridge is based on [RATmeter](https://github.com/Kuroukihime/AIon2-Dps-Meter). License information is included in the release ZIP and the repository [LICENSE](LICENSE).
