# A2Companion

Free modular companion for Aion 2. Previously named Aion2SmartMeter.

[Download the latest Companion release](https://github.com/panparsifaluniverse/Aion2SmartMeter/releases/latest)

The Companion ZIP contains the application, licenses and documentation. Extract the ZIP, close the previous Companion completely, and run the new EXE. Open **Companion > Modules** to install tools or **Update installed** to update existing modules. Module preferences and character data are preserved. English, Italian and Estonian are supported.

## Latest: v1.260

- Games introduces **Mochipi**, a cozy fantasy pet with an egg, five families and twenty forms, care stats, quests, a Pet Store, an album and resources earned through Loot. Evolution requires EXP, materials and hunting goals, without minimum age or farming-hour gates. The virtual exchange market rotates hourly.
- Mochipi Friends supports friend requests, notifications and reciprocal one-hour pet visits with EXP and resource rewards. Use an updated Companion with Games installed and relog your character to appear in the directory. Both pets must be hatched to visit.
- Fixed close buttons accidentally moving module windows, including the compact Radar. The shared protection also supports previously installed modules and recovers from a mouse release outside the window.
- Pinned timers use two columns. Soul Tracking omits the `(Bound)` suffix from displayed Soul names.

[Full release notes and download](https://github.com/panparsifaluniverse/Aion2SmartMeter/releases/tag/v1.260)
